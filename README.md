# Olino Uniforms — Institutional Uniform Atelier

> "Weaving the Uniformity with Royal Precision."

Official website for **Olino Uniforms**, Kerala's premier institutional uniform atelier and school wear manufacturer with production depots in **Nilambur** and **Angamaly**.

---

## 🌟 Key Features

- **Executive Aesthetic**: Luxury imperial royal purple, pure silk white, and precision slate grey color architecture.
- **Interactive Portfolio**: Filterable showcases for Dedicated Blazers, Kindergarten Uniforms, Boys' & Girls' Formals, Sports House Wear, College Attire, and Uniform Accessories.
- **Accessory Gallery**: High-definition product showcases for custom school ties, embroidered bullion badges, combed cotton socks, vulcanized leather shoes, and institutional belts.
- **Certified Mill Assurance**: Highlighting authentic supply chain certifications (Mafatlal Since 1905, S.Kumars).
- **Manufacturing Roadmap**: 5-step institutional production process from CAD digital grading to on-campus fitting.
- **Factory Hubs**: Direct contact details and maps for Nilambur (`+91 7902833334`) and Angamaly (`+91 8075022663`).
- **100% Lightweight & Fast**: Built with pure semantic HTML5, modern CSS3 (Custom Properties & Grid), and vanilla JavaScript with zero external runtime framework dependencies.

---

## 🚀 Running Locally

1. Clone or download this repository.
2. Double-click [index.html](index.html) to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, run `start-server.bat` to launch a local Python HTTP server.

---

## 🌐 Deploying to GitHub Pages

1. Go to repository **Settings** on GitHub.
2. Click **Pages** in the left sidebar.
3. Under **Branch**, select `main` and root `/`.
4. Click **Save**. Your site will be published at `https://<username>.github.io/<repo-name>/`.
